
**Tauri + Web 前端 + FastAPI Python sidecar**。  
这是更适合“漂亮桌宠 + 复用现有 Python 后端 + 未来三端”的路线。

**总体架构**
```text
Tauri App
├─ Web 前端：React/Vue/Svelte
│  ├─ 桌宠透明窗口
│  ├─ 动画状态机
│  ├─ 气泡/菜单/托盘设置页
│  └─ 通过 HTTP/WebSocket 连接本地 FastAPI
│
├─ Tauri Shell
│  ├─ 创建透明、无边框、置顶窗口
│  ├─ 系统托盘
│  ├─ 启停 Python sidecar
│  ├─ 打包安装包
│  └─ 平台能力：开机启动、窗口拖拽、全局位置保存
│
└─ Python Sidecar
   ├─ FastAPI 本地服务
   ├─ 复用 danling readers/engine/remote/hardware
   ├─ 输出 DanLingState JSON
   ├─ WebSocket 推送状态
   └─ 管理配置、远程 profile、日志路径
```

**推荐技术栈**
| 模块 | 技术 |
| --- | --- |
| 桌面容器 | Tauri v2 |
| 前端框架 | React + Vite + TypeScript，或 SvelteKit |
| UI 样式 | CSS Modules / Tailwind / UnoCSS |
| 动画 | CSS sprite + Lottie，可后续接 PixiJS |
| 后端 API | FastAPI + Uvicorn |
| 实时通信 | WebSocket |
| 后端复用 | 当前 `danling` Python 包 |

| 配置存储 | 继续复用 `danling.yaml`、`~/.danling/remote_profiles.json` |
| 本地状态 | `~/.danling/state.json` 或 SQLite，可先 JSON |

**FastAPI API 设计**
```text
GET  /health
GET  /api/state
GET  /api/config
PUT  /api/config
GET  /api/remote/profiles
POST /api/remote/profiles
POST /api/source/select
WS   /ws/state
```

`/api/state` 返回现有 `DanLingState.to_dict()`，前端只关心：
```json
{
  "pet_name": "DanLing",
  "pet_mood": "happy",
  "furnace_state": "burning",
  "realm": {},
  "metric": {},
  "hardware": [],
  "events": []
}
```

WebSocket 每 1-2 秒推送一次状态。前端根据：
- `pet_mood` 切换宠物表情和动作
- `furnace_state` 切换炼丹炉特效
- `events` 触发气泡提示
- `hardware` 显示 GPU 温度/显存风险

**Tauri 侧职责**
Tauri 不做业务逻辑，只做桌面壳：

- 启动时拉起 Python sidecar
- 探测 FastAPI `/health`
- 创建透明、无边框、置顶宠物窗口
- 提供系统托盘：显示/隐藏、切换模式、退出
- 保存窗口位置
- 退出时关闭 sidecar
- 后续接开机自启、快捷键、通知

Tauri v2 支持 sidecar 能力，适合带一个外部二进制一起发布。官方文档：  
https://v2.tauri.app/develop/sidecar/

**Python sidecar 打包**
Windows 第一版：

```text
pyinstaller danling_api_main.py
→ 生成 danling-sidecar.exe
→ 放进 desktop/src-tauri/binaries/
→ Tauri bundle 时一起带上
```

注意：PyInstaller 不是交叉编译工具，Windows 包在 Windows 构建，macOS 包在 macOS 构建，Linux 包在 Linux 构建。官方说明：  
https://pyinstaller.org/en/stable/requirements.html

**开发流程**
1. 先加 `src/danling/api/`，把现有状态能力封成 FastAPI。
2. 加 `/api/state` 和 `/ws/state`，本地 `uvicorn` 能跑。
3. 建 `desktop/` Tauri + React/Vite。
4. 前端先 mock 状态，再接真实 FastAPI。
5. Tauri 启动 sidecar，并轮询 `/health`。
6. 做透明置顶桌宠窗口、托盘菜单、退出清理。
7. Windows PyInstaller + Tauri bundle。
8. 再做 macOS/Linux CI 和平台差异适配。

**我推荐的第一版 MVP 功能**
- Windows 透明置顶桌宠
- 可拖拽位置并保存
- 托盘显示/隐藏/退出
- 读取本地训练日志

- 宠物根据 `pet_mood` 变动作
- 事件气泡提示
