# DanLing v1.1.0

v1.1.0 聚焦远程训练可视化：在本地终端通过 SSH 密钥读取远程训练日志，并同步展示远程 NVIDIA GPU 状态。

## 新增功能

- 新增 `danling remote setup PROFILE`，用 Textual TUI 辅助配置远程主机、日志目录和 SSH 私钥。
- 新增 `danling remote status/watch/tui PROFILE`，定期通过 SSH 读取远程 Ultralytics `results.csv`，复用现有状态推理和展示引擎。
- 新增 `danling remote hardware PROFILE`，单独查看远程 NVIDIA GPU 利用率、显存、温度和功耗。
- 远程监控强制使用 SSH key 和 `BatchMode=yes`，避免运行期间卡在密码输入。
- 远程 GPU 查询会尝试 `nvidia-smi`、`/usr/bin/nvidia-smi` 和 `/usr/local/cuda/bin/nvidia-smi`，并复用本地 NVIDIA CSV 解析逻辑。

## 使用示例

```bash
danling remote setup trainbox
danling remote hardware trainbox
danling remote status trainbox --config danling.yaml
danling remote tui trainbox --config danling.yaml
```

当前远程监控支持 Ultralytics `results.csv` 和官方控制台 `.log/.txt`。TensorBoard 远程日志镜像、远程 Ascend/NPU 读取和远程配置文件字段会在后续版本继续补齐。
