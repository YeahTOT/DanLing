# DanLing v1.2.0

v1.2.0 聚焦配置逻辑、配置 TUI 和硬件监控界面的可用性打磨，让本地和远程训练监控更少依赖重复命令参数。

## 主要更新

- `danling.yaml` 新增 `source` 和 `data_path`，`danling watch` / `danling tui` 可直接从配置文件读取默认日志类型和路径。
- 配置 TUI 新增数据源配置页面，支持在界面里选择 `auto`、Ultralytics `results.csv`、官方 `.log/.txt` 和 TensorBoard event/logdir。
- 自动生成配置支持 Ultralytics 官方控制台日志，适合 `nohup.out`、`train.log` 等后台训练输出。
- Textual 监控 TUI 的硬件区域改为进度条展示，并补充主机 CPU 与系统内存占用。
- 远程 profile 可关联本地配置文件，远程 `status/watch/tui/inspect/doctor` 可复用配置中的日志路径和数据源。
- 默认日志过期判断从 5 分钟调整为 1 小时，更适合长 epoch 训练。

## 使用示例

```bash
danling init
danling config tui

# 配置 source 和 data_path 后可省略 PATH 与 --source
danling watch --no-hardware
danling tui --no-hardware

# 远程 profile 也可复用配置中的 source/data_path
danling remote trainbox status --config danling.yaml
danling remote trainbox tui --config danling.yaml
```
